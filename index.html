SOLANA WORKSHOP #3　③ 発表資料の作成

発表資料スクリプト作成ツール

チーム情報を入力して「スクリプトを作成」を押すと、勉強会資料のスクリプト全文（付録 1/4〜4/4）をもとにした、Claude Code にそのまま貼り付けられる文章ができます。解決したい課題がない「アイデア型」の作品にも対応しています。

  • 1「発表の型」を選び、下の項目にチームの内容を入力する（埋められない項目は空欄のままでよい）
  • 2「スクリプトを作成」を押し、「コピー」でスクリプトをコピーする
  • 3Claude Code パネルの入力欄に貼り付けて送信する

チーム情報の入力

空欄の項目は【　　　】のままスクリプトに入ります。Claude Code が資料を作る前に、特に重要な不足を質問してくれます。

注意 入力内容はこのページの中だけで使われ、どこにも送信・保存されません。ページを閉じたり再読み込みしたりすると消えるので、作成したスクリプトはコピーか「テキストで保存」で控えておいてください。

作成されたスクリプト

内容を確認して、Claude Code パネルの入力欄に貼り付けてください。この欄で直接書き直すこともできます。

POINT 生成された発表資料は必ず自分たちで読み直し、実際に作ったものや数字と違うところは、Claude Code に指示して直してから使ってください。
